# AGENTS.md — Open Date

Brief for coding agents working on (or with) this repo.

## What this is

A static React SPA demonstrating **progressive fit filtering**: one pure-TypeScript engine (`src/engine/`) drives both a dating-discovery vertical (`/#/date`) and a scholarship-fit vertical (`/#/scholarships`). No backend, no auth, no real data — fixtures in `src/fixtures/*.json` are synthetic.

## Commands (all deterministic, no hidden steps)

| Task | Command |
|---|---|
| Install | `npm install` |
| Dev server | `npm run dev` → http://localhost:7643 |
| Typecheck + build | `npm run build` (outputs `dist/`, base path `/open-date/`) |
| Unit tests | `npm test` (vitest, engine only) |
| Fixture sync | `npm run sync-fixtures` (fixtures → `public/api/`, runs automatically in dev/build) |

Smoke routes: `/#/` (home), `/#/date`, `/#/scholarships`, `/#/agent`. All render without any user setup; the two verticals start with an archetype picker.

## Invariants to preserve

1. **Engine purity** — `src/engine/` imports no React and touches no storage. All state derivation is replay: `replayFeedback(seedModel(archetypes), events, …)`.
2. **Journal-first** — `FeedbackEvent[]` / `FactEvent[]` are append-only sources of truth; `PreferenceModel` and `FactSheet` are derived. Never persist derived state as authoritative.
3. **Explanations from the model only** — UI and agents explain rankings via `ScoreResult.contributions` / `FitResult.rows`, never invented prose.
4. **Fixtures are the single source** — `public/api/` is generated by `scripts/sync-fixtures.mjs`; edit `src/fixtures/`, not the copies.
5. **Synthetic data only** — do not add real people, real scholarships, or scraped content.
6. **Reasons have semantics** — a new feedback reason must declare `effects` (trait delta / veto) and/or `matchingFacets`; a label without semantics teaches the model nothing.

## Data contract

`src/fixtures/contract.json` (served at `api/contract.json`) is the canonical machine-readable contract: entities, the filtering loop, session-state shape (`localStorage` key `open-date:v1`), and sanctioned agent tasks (prefilter, explain, clarify, extend facets, summarize drift). The `/#/agent` page exposes export/import and a copyable agent brief.

## Deploy

GitHub Pages via `.github/workflows/deploy.yml` — builds on push to `main`, publishes `dist/`. Live at https://jacobcole.ai/open-date/ (custom domain on the tmad4000 user site). Vite `base` is `/open-date/` in production; keep hash routing so Pages needs no rewrites.
